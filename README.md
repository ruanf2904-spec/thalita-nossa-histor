# Nossa História — Ruan ♥ Thalita

Um site romântico que conta a nossa história, com contador desde **17/04/2025** e um álbum surpresa com **28 fotografias** revelado ao abrir o envelope.

## Publicação pelo GitHub Pages

O HTML e o fluxo automático do GitHub Pages já foram configurados neste repositório.

**Falta somente o arquivo ZIP que contém as 28 fotos.**

1. Faça o upload **sem descompactar** do arquivo `ruan-thalita-album-surpresa-para-publicar.zip` na raiz deste repositório, na branch `main` (Add file → Upload files → Commit changes).
2. A ação `Publicar Nossa História no GitHub Pages` será executada automaticamente. Ela extrai o ZIP, confere as 28 fotos e publica o conteúdo.
3. Se necessário, abra **Settings → Pages → Build and deployment → Source** e escolha **GitHub Actions**.
4. Confira o resultado em **Actions** e, quando estiver concluído, em `https://ruanf2904-spec.github.io/thalita-nossa-histor/`.

**Aviso de privacidade:** o repositório é público e as fotos do casal ficarão acessíveis a qualquer pessoa que tenha o link ou encontre os arquivos.

Os arquivos na pasta `imagens/` são incluídos no ZIP; não é necessário enviá-los individualmente.
